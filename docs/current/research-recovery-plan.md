# 连接恢复、提前展示结果与按缺口研究

2026-10-04 开始。继续使用 Pydantic AI、socai、FlyAI、SerpAPI、Session 和 Evidence；不新增来源。

1. 每次连接记录 daemon、浏览器连接、授权是否已确认、endpoint 指纹及可取得的断开诊断。状态查询不触发重新连接；不重启 daemon 或 Chrome。页面失败与 CDP 断开分别处理，无法确认授权弹窗或断开原因时写明未知。
2. 在已有 Session 内恢复未完成的查询和日期请求。成功步骤保留，旧报价保留取得时间并按新鲜度决定是否重查；网页提供“恢复这轮研究”，与新一轮提问区分。
3. 首批正文取得后筛选有引用的候选，开始日期探索及验价，同时继续串行社区读取。共享票价调用预算和并发限制，记录第一条、第三条可核对结果出现时间。
4. Agent 根据已有正文、候选、日期覆盖、来源失败和剩余预算选择搜索社区、探索日期、在已有社区渠道核查促销或停止。程序检查引用、操作范围和预算，保留实际决定及结果，不展示私有推理。

验证包括回归测试、多次新进程/新 Session 的真实研究、连接建立后的连续及空闲重复调用，以及失败会话恢复。记录 complete / partial / blocked、每次弹窗是否被用户实际观察到、调用量、耗时、连接变化和恢复时跳过的成功步骤。没有外部报价或正文时不使用历史结果填充新研究。
